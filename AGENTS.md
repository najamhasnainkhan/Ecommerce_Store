# Agents

## Stack
- Frontend: React 18 with Vite
- Backend: Python FastAPI
- Communication: REST API with JSON

## Conventions
- Frontend source in `src/`
- Backend source in `server/`
- React components are functional with hooks
- Styling is minimal inline for MVP

## Run
- `npm install` to install frontend dependencies
- `npm run dev` to run both frontend and backend concurrently

## Decisions
- No user authentication for simplicity
- Simulated order placement
- In-memory data for MVP
