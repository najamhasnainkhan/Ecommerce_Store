# E-commerce Store

This is a small e-commerce store web application similar to Shopify. It allows customers to browse products, add them to a cart, and place orders. The app uses a React frontend and a Python backend.

## Features

- Browse products with details including name, price, and image.
- Add products to a cart.
- Place orders with order confirmation.

## Tech Stack

- Frontend: React with Next.js (App Router)
- Backend: Python (to be added)

## Running the Project

1. Install dependencies:

   ```bash
   npm install
   ```

2. Run the development server:

   ```bash
   npm run dev
   ```

3. Open http://localhost:3000 in your browser.

## Notes

- No user authentication is implemented.
- Payment processing is simulated.

## Environment Variables

- DATABASE_URL: PostgreSQL connection string
- SESSION_SECRET: Session signing secret

Add these to the Secrets panel.
